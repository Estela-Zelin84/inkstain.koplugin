# KOReader 阅迹壁纸

这是一个用于 KOReader 的锁屏/休眠壁纸插件，参考 ReadTrace 的“阅读账单”样式实现。

插件会读取 KOReader 内置阅读统计数据库 `statistics.sqlite3`，生成一张适合墨水屏显示的 PNG 壁纸，并可自动把 KOReader 的休眠屏幕图片来源切换为这张单独图片。

## 功能

- 生成“阅读账单”风格锁屏壁纸。
- 支持统计今天、最近 7 天、最近 30 天。
- 显示本期总时长、书籍数、Top 书单、进度估算、每日阅读趋势和条码装饰。
- 自动按屏幕宽高比例重新分配页眉、书单、图表和底部条码区域。
- 底部使用内置 GitHub 二维码资源、Code128 风格条形码、随机格言和作者署名。
- 支持休眠前自动刷新：只有当前正在使用阅迹壁纸时才刷新，不会在你切回原生屏保后再次覆盖。
- 支持一键关闭阅迹壁纸，停止自动刷新并恢复启用阅迹前的 KOReader 原生屏保设置。
- 支持设置锁屏使用范围：只在主页使用，或主页和阅读界面都使用。
- 使用 KOReader 自带文字渲染组件生成 PNG，避免部分设备上 SVG 文字空白。
- 不依赖网络、不依赖外部命令、不读取微信读书或 BOOX NeoReader 数据。

## 安装

1. 把整个 `readtrace.koplugin` 文件夹复制到 KOReader 的 `plugins` 目录。
2. 重启 KOReader。
3. 打开 KOReader 顶部菜单，在原来的插件菜单位置找到 `阅迹壁纸`。
4. 如未显示，请先到“插件管理”确认 `阅迹壁纸` 已启用。
5. 点击 `生成并设为休眠壁纸`。

生成后的壁纸会保存在：

```text
koreader/screensaver/readtrace_png/readtrace_wallpaper.png
```

插件会自动设置：

```text
screensaver_type = document_cover
screensaver_document_cover = koreader/screensaver/readtrace_png/readtrace_wallpaper.png
```

启用阅迹前，插件会备份 KOReader 原来的休眠屏幕相关设置；执行 `关闭阅迹壁纸` 后会按备份恢复。

## 使用前提

请先在 KOReader 中启用内置“阅读统计”插件，并正常阅读一段时间。否则插件找不到 `statistics.sqlite3` 时，会生成一张提示壁纸。

## 菜单说明

- `生成并设为休眠壁纸`：生成壁纸，并设置为 KOReader 休眠屏幕来源。
- `关闭阅迹壁纸`：停止休眠前自动刷新；如果当前休眠屏幕正使用阅迹壁纸，会恢复启用阅迹前的原生屏保设置。
- `仅生成壁纸`：只生成壁纸，不改变 KOReader 屏保设置。
- `休眠前自动刷新`：每次休眠前自动刷新壁纸，默认开启。
- `自动设置 KOReader 休眠屏幕`：生成后自动修改屏保设置，默认开启。
- `锁屏使用范围`：选择只在主页休眠时使用，或主页和阅读界面休眠时都使用。选择“只在主页使用”时，插件不会在阅读界面休眠前生成、恢复或修改屏保设置。
- `统计周期`：选择今天、最近 7 天或最近 30 天。
- `书单数量`：选择书单显示数量。
- `显示输出路径`：显示壁纸输出路径。

## 排版说明

当前版本使用之前的收据/阅读账单布局，并根据设备屏幕比例自动计算四个区域：

- 页眉：单号、统计周期、来源、总时长、书籍数。
- 书单：最多显示 4 本，屏幕矮时会继续省略多余书籍，避免文字重叠。
- 图表：固定保留底部空间，显示每日阅读趋势折线。
- 底部：GitHub 二维码、Code128 风格条码、随机格言和 `Design by Estela-Zelin84` 署名。
